PASOS RAPIDOS

1. Sube esta carpeta a GitHub.
2. NO subas un token real.
3. En tu PC o hosting, crea config.json copiando config.example.json.
4. Instala dependencias con: npm install
5. Registra comandos con: npm run deploy
6. Inicia el bot con: npm start

Para invitar el bot al servidor usa scopes:
- bot
- applications.commands

Permisos recomendados:
- View Channels
- Send Messages
- Use Slash Commands
- Connect
- Speak
